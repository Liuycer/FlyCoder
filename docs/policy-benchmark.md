# 策略评测与并列累计实验

连接组只选择 READ、EDIT、TEST、RETRY、DONE；语言和代码由 coding adapter 处理。本实验没有训练权重，也不证明果蝇理解代码。

## 评测集

`benchmarks/tasks.json` 定义四种 bug：平均值、区间裁剪、保序去重、列表分块。每项包含独立的小仓库与至少三项测试。参考修复放在仓库外，不能通过 Git sandbox 的代码上下文传给真实 LLM。

默认 coding adapter 使用预先固定的候选：clamp 第 1 次、average/chunks 第 2 次、unique 第 3 次编辑得到正确实现。之前的候选仍有可被测试发现的问题。这衡量动作调度能力，不衡量 LLM 编程能力。状态编码不包含任务语义，因此具有相同状态轨迹的不同 bug 并非独立的神经输入实验。

比较四种策略：规则 mock、带种子的随机策略、原始 MaleCNS、并列累计 MaleCNS。每项使用种子 0/1/2，共 48 次运行。种子影响随机策略；固定权重神经后端不因种子变换而生成独立样本，所以神经策略的三个种子重复不能当成三个独立的统计样本。

所有策略共享 12 动作、3 次编辑、每次测试 15 秒的预算与合法动作约束。神经窗固定 100 ms，所有神经运行最多 36 窗；原始策略每次动作只用一窗，实验策略最多三窗。额外计算量单独记录，不能称作等算力比较。

```bash
.venv-neural/bin/python scripts/benchmark_policies.py
```

脚本在新的 `research/benchmark-<id>/` 保存逐运行 Git 副本、事件、代码 diff 和 `report.json`。报告包含成功率、动作数、并列次数、最终并列停止次数、coding adapter 调用数、模拟窗数、模拟时间和墙钟时间。所有神经运行均通过证据验收器后才计入报告；后端/证据错误会让脚本失败，而不是悄悄计作正常策略停止。

默认不调用付费 LLM，`llm_calls=0, cost_usd=0`。显式加 `--live` 才读取 `.env` 中配置的真实接口。此时记录 READ/EDIT 逻辑调用数（不包含内部 HTTP 重试次数），费用为 `null`，需查供应商账单；没有凭空估算 token 费用。实时 LLM 响应存在随机性，需与固定候选结果分开解释。

## 实验策略

默认 `--tie-extra-windows 0`，保持既有并列即停止的行为。设置为 1 或 2 后：

1. 正常模拟一段 100 ms，计算合法动作分数。
2. 若最高分并列，保持同一输入刺激，继续模拟；神经状态不重置。
3. 将本次选择所有窗口的读出脉冲数相加，再除以读出神经元数和累计时间，得到平均放电率。
4. 首次得到唯一最高分就选择该动作；达到额外窗口上限仍并列则停止，不随机回退、不按动作优先级打破并列。

初始读出全部沉默仍停止。延长采样是一项工程设计，不是生物学习或针对正确动作的奖励调参。

```bash
./run-neural.sh --llm mock --tie-extra-windows 2
```

每次选择保留 `flycoder.neural-accumulation.v1` 聚合 trace 及全部原始 `windows`。原始放电数组哈希只存在各窗口内，不把哈希或计数拼接冒称为累计完整放电数组。checker 校验窗口连续性、同一刺激/图/读出映射、追加前确有并列、窗口预算、累计计数/时间和最终合法最高分。

## 远程验证

已有 `FlyCoder neural Docker check` 工作流新增可选 `benchmark` 输入，默认关闭。开启后在无网络、非 root、只读根目录、4 GiB 内存和 2 CPU 的 x86_64 容器中运行相同评测，并上传 `benchmark/` 产物。原来的 demo 与验收流程仍按默认策略执行。

## 本机初次结果

本机 macOS ARM64，4 个任务 × 3 个种子：

| 策略 | 完成次数 | 平均动作数 | coding 调用总数 | 模拟时间总计 |
| --- | --- | --- | --- | --- |
| mock | 12/12 | 7.00 | 36 | 0 |
| random | 11/12 | 7.83 | 56 | 0 |
| 原始 MaleCNS | 12/12 | 8.00 | 48 | 9600 ms |
| 累计 MaleCNS | 12/12 | 8.00 | 48 | 9600 ms |

本机没有触发并列，无法据此证明累计策略有改进。结果不支持连接组优于规则策略的结论。原始记录位于 `research/policy-benchmark-mac/`。
